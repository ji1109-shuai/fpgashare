# 摄像头支架转接件 V0.1

这是第一版尺寸试装模型，尚未经过切片预览、打印、承载及现场调焦验证。不是已完成的整套支架。保留现有支架、摄像头和开发板上的保护结构。

## 测量依据与暂定项

- 用户确认：摄像头 PCB 34×34 mm，横纵孔中心距约31 mm，PCB 孔径约2 mm；支架圆环内径约42 mm，上下厚度约18 mm。
- 用户确认：开发板含亚克力、螺丝和元件的最大外形为130×90×27 mm。该尺寸不是盒子内尺寸。
- 打印配合暂定：直径间隙0.6 mm，因此插入段外径41.4 mm；打印孔径2.3 mm用于M2螺丝通过。不要将摄像头PCB孔扩成2.3 mm。
- 尚未实测：镜头固定座外形及背面元件高度、实际螺母尺寸、圆环外径及上方空间、旋钮压紧位置、开发板托架与升降头的固定位置。
- 镜头避让孔暂定30 mm，支撑柱高6 mm，止挡边外径52 mm。必须核对实物，不得从这些暂定值反推实际尺寸。镜头不作为夹持部位。

## 文件与试装次序

1. `hole_coupon.stl`：40×40×2 mm薄片，先检查四孔与PCB是否对齐、镜头座是否能避让。只能轻放检查，不压在元件上，不带电试装。
2. `ring_coupon.stl`：短插入段4 mm，先检查外径与圆环是否配合，止挡边是否与横臂干涉。这不是承载测试件。
3. `camera_mount.stl`：完整摄像头转接座。插入段18 mm，上方止挡边3 mm，四个支撑柱6 mm，总高27 mm。止挡边落在圆环上，原旋钮压紧打印件。未验证前不悬挂设备。

STL坐标单位按mm解释，切片时保持100%比例。为匹配相邻结构，不能通过整体缩放修正孔距或孔径。

完整件上有四个顶部开放的M2六角螺母槽：先放螺母，再装PCB，从PCB上方穿螺丝。六角槽对边暂定4.2 mm、深2 mm；实际螺母应能平放在槽底，不能高出支撑面。建议用尼龙垫圈，轻拧固定，确认垫圈及支撑面不触碰元件。M2×6可作为候选，最终长度根据PCB厚度、垫圈和实际螺母确认。不要把螺丝拧进摄像头中间已有的镜头座固定孔。

支撑柱和螺母槽可能与边角元件、焊点干涉，需要检查PCB两面。镜头会进入转接座中央空腔，必须实测其固定座、转动范围及手指调焦空间；如不合适，应改孔径或高度再生成模型。

完整件按当前STL方向（插入段向下）打印时，止挡边是悬空外沿；需要在切片器中检查并设置适当支撑。支撑应避免堵住螺母槽和螺丝孔。第一版可先用PLA小件试配，最终材料与壁厚依据实际温度、夹紧力及承载决定，不宣称已验证强度。

## 调整尺寸

用OpenSCAD打开 `camera_mount.scad`，直接修改参数；`part` 可选 `camera_mount`、`hole_coupon` 或 `ring_coupon`。渲染后重新导出对应STL。现有STL不会随参数编辑自动更新。

也可以修改 `parameters.json`，安装Python依赖 `numpy manifold3d Pillow` 后执行：

```powershell
python .\mechanical\camera_mount\build_models.py
```

脚本会覆盖本目录生成的SCAD、STL、预览和验证报告。经此方式修改时，以JSON为参数来源；不要同时在SCAD和JSON里维护不同参数。当前STL由Manifold几何内核生成，SCAD表达同一结构；本机没有OpenSCAD，本次没有执行OpenSCAD渲染。

`validation.json` 仅记录几何内核状态、体积、边界尺寸和三角网格闭合检查。它不证明打印配合、螺母压入效果、夹持强度或镜头视野已通过。

## 开发板托架后续

计划承托现有亚克力底板，接口侧开放，并与摄像头安装在同一升降头上，随高度一起移动。尚缺升降头顶部安装面、可用固定孔和干涉空间的尺寸，因此本版不生成缺少固定依据的大托架。板盒内尺寸还需在130×90×27 mm基础上增加装配余量。
