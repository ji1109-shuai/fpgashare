# 摄像头偏绿诊断版（2026-10-17）

用户已下载无效白平衡回退修正版，持续偏绿时 REF:BAD；安路图标和白色文字正常。这将排查重点放到摄像头图像分支，但还不能仅凭照片区分传感器/照明、RAW 插值、白平衡实际状态及视频数据处理。

## 如何编译和观察

1. 使用当前工作目录下的 `_osd_1/td_project/camera_to_dsi_display.al`，从综合重新运行，并完成布局布线。仅重新 bitgen 不会包含源码改动。之前暂停的 ChipWatcher 实例继续保持禁用即可。
2. 检查最终全局 SWNS、HWNS 均不小于 0，违例端点为 0。通过后由用户生成 bit 并下载。本次未运行 TD 综合、布局布线或生成 bit，功能仿真不证明时序已经收敛。
3. SW1/SW2/SW3 全关，看 RGB 原图。先保留当前可稳定识别形状的曝光/增益以及当前 SW4 状态，不要为采集第一组数据调整参数。
4. 等待两秒后拍摄完整屏幕，要能看清 EXP、GAIN、WB/REF 和下述六行。第一组保留偏绿现场与零件摆放。
5. 第二组：移走中心零件，将普通哑光白纸平放在零件所在平面，覆盖画面中心。中心采样窗口为 x=608..671，y=328..391，大小 64x64。先保持第一组设置拍照；再关闭 SW4，等两秒后再拍一张。
6. 如果出现 WB:CAL REF:OK，打开 SW4，确认 WB:LOCK REF:OK，移开白纸、放回零件，再拍一张。若始终 BAD，不需要不断尝试曝光/增益，直接回传诊断行。
7. 若重新出现“调增益时短暂正常”，记录前后 EXP、GAIN 和 WB/REF，尽可能同时拍下诊断行。增益改变后校准会失效，需重新校准才可恢复有效颜色分类。

需要回传的是上述完整屏幕照片；不用手动换算数字，不需要先抓 ChipWatcher 波形。

## 新诊断行

新行位于图标右侧原控制区域下方，x=176..431、y=104..219，不绘制额外检测框。WB/REF 状态仍在 y=84..99。数字均为十六进制。

| 示例 | 含义 |
| --- | --- |
| `RAW:80C080` | 去马赛克后、白平衡之前的中心 RGB 均值，依次为 R=128、G=192、B=128。包含被校准拒绝的像素；不会因 REF:BAD 变成空白。若样本总数不完整则显示横线。 |
| `R:1000 B:1000` | 已实际用于刚统计帧的红、蓝补偿，显示为 Q12：1000=1 倍，1800=1.5 倍，2000=2 倍，0800=0.5 倍。不是传感器 GAIN，也不是尚未生效的目标增益。绿色仍为直通。 |
| `OK:0400 N:0400` | 通过校准采样门限的数量和总采样数量。每拍只取像素 0；64x64 区域正常总数 1024，即 0400。 |
| `HI:0400 LO:0000` | HI：任一通道 >240 的高亮样本；LO：未计入 HI 且任一通道 <64 的暗样本。HI 预警不等于已经物理饱和到 255。 |
| `CAST:0000` | 未计入 HI/LO，且最大通道 > 最小通道 2 倍的样本数。 |
| `SMP:CLIP` | 样本不足时数量最多的拒绝类别，或下述其他状态。 |

HI/LO/CAST 互斥，和 OK 的和应为 N，方便对照。RAW 均值独立统计全部窗口像素；REF 中的校准均值只来自合格样本，两者含义不同。

- `SMP:OK`：合格样本至少 128；仅表示软件采样门限通过，不保证参考物确实为中性白，也不等于白平衡已经收敛/锁定。
- `SMP:CLIP`：合格样本不足，主要因某通道过亮。
- `SMP:DARK`：合格样本不足，主要因某通道过暗。
- `SMP:CAST`：合格样本不足，主要因通道比例超限。
- `SMP:EMPTY`：中心区域未收集到样本。
- `SMP:STREAM`：样本数量与预期不符，优先检查帧/行有效节拍。
- `SMP:WAIT`：尚未发布第一份完整统计。

## 如何依据结果定位

- 持续 BAD，R/B 均为 1000，RAW 的 G 明显高于 R/B：偏色在白平衡输入处已经存在，需分析照明、传感器、RAW 处理或参考拒绝原因；不是旧红蓝补偿残留的直接证据。
- 持续 BAD，R/B 多帧后仍不是 1000：与修正版预期不符，先核实下载版本、实际复位及补偿状态。
- 白纸中心 SMP:CLIP：参考窗口高亮样本过多。优先在白纸受光/补光条件上获得有效参考；不要仅为颜色改变已验证的轮廓参数。
- 白纸中心 SMP:CAST：当前“近中性”软件门限可能阻止对严重原始偏色的校正，需要根据 RAW 数值调整校准策略。
- SMP:OK 但 WB:LOCK REF:BAD：锁定状态不能自动接受新参考，需先关闭 SW4 校准，待 OK 再锁定。
- RAW 看起来接近中性，实际 R/B=1000，摄像头画面仍明显偏绿：继续检查中心以外区域，以及白平衡之后的视频数据排列/存储/显示分支，不能单凭中心均值认定整幅图无偏色。

诊断以刚结束的摄像头帧统计并保持，经过事件同步后只在显示帧起始生效。显示的现有 WB/REF 与新诊断使用独立事件，切换瞬间可能相差少量帧，应观察稳定两秒后的结果。

## 实现与验证边界

- 新统计使用 3 个 18 位累加器、5 个 11 位计数器、固定右移均值和帧保持数据包。没有新增乘法器、除法器或图像行缓存；没有改变像素流、时序、FIFO 和识别数据路径。
- 观察器要求中心 ROI 的像素 0 采样数为不超过 1024 的二次幂；生产配置固定为 1024。
- 生产 AWB 与关闭观察器的 AWB 同时运行，逐拍比较有效像素、帧/行侧带和校准事件，防止诊断改变原路径。
- OSD 仿真对实际输出像素逐点比对，包含安路图标、四个物品标签、十六进制诊断行、跨域帧保持及目标移除。
- `before/` 为本次生产源修改前的快照，`source/` 为交付源码快照，`logs/` 和 `validation_summary.txt` 为验证证据。功能测试不包含现场光谱和真实 RAW 输入；仍需上板数据才能确定偏绿根因。
