# 安路图标恢复与四目标零件识别

工程：`D:/FPGA_competition/7_lab_ex_2026_nosoft/lab_hd_3_osd_1`。继续使用 `td_project/camera_to_dsi_display.al`。本轮只修改已有生产源文件，不需要向 TD 添加新文件。未运行 TD 综合、布局布线、生成或下载 bit，物理资源和最终时序由重新构建的报告确认。

## 屏幕变化

- 恢复原来的安路图标、原调色板和位置，位于左上角。
- RGB／GRAY 等模式、EXP、GAIN、WB 状态移到图标右侧。默认隐藏此前占据左侧的大块 RGB／投票诊断数字。
- 同画面最多四件零件，各自显示品红框和“颜色 + 类别”，例如 `SILVER WASHER`、`RED NUT`、`BRASS SCREW`、`BLACK SQNUT`。
- 螺丝、平垫、六角螺母、四方螺母经过三次有效分析确认后才显示。颜色独立确认两次；形状正确但颜色证据不足时显示 `UNKN`，保留形状框。未识别轮廓和候选框不显示。
- 四件结果在同一显示帧边界一起更新。拿走零件后，新分析批次会清除其框；不是在手离开瞬间更新。

## 上板操作

1. 在 `_osd_1` 工程中自行重新综合和布局布线，检查资源报告及最终 routed timing，确认 SWNS／HWNS 均非负，再生成、下载 bit。本轮没有改动引脚和时钟约束。
2. 固定摄像头高度、背光和正面照明；SW1～SW3 全关观察 RGB。SW4 关闭，在零件所在平面放同一张哑光白卡覆盖画面中心 64×64 像素（1280×720 时 x=608～671、y=328～391）。
3. 保持当前曝光、增益，等待 `WB:CAL REF:OK`；打开 SW4，确认 `WB:LOCK REF:OK`，再移走白卡。白卡过曝或太暗会显示 BAD，应先调整曝光／增益。
4. 先同时放两件不同颜色的零件，再增加到四件。零件不能接触或叠放，轮廓之间建议至少留 24～32 像素，白板边缘也留出明显空隙。为便于观察，避开左上角图标和右侧状态文字，标签之间留出空间。放稳后等待约 1～2 秒观察结果。
5. 四件共用一组曝光、增益、白平衡。先比较同组条件下的颜色，不要每件单独调参。交换零件的位置再拍一张，可以区分材质偏差与局部照明偏差。
6. 若改变曝光、增益、摄像头高度或灯光，重新执行白卡校准、锁定。EXP／GAIN 改变会使原校准失效，重新校准前颜色为 UNKN。单纯切换当前编辑 EXP 或 GAIN，不会清除校准。

按键不变：KEY1 减小、KEY2 增大；同时长按约 0.8 秒切换曝光／增益，黄色文字表示当前编辑项。SW4 控制白平衡校准／锁定。

## 实现范围与限制

沿用“先找白色背光板真实边界，再找边界内连通物体”的方法。按图像扫描顺序保存前四个满足面积／边界要求的暗连通区域，逐件复用一套形状分析电路，并分别统计目标内部颜色。没有复制四套形状计算器，也没有改变视频／DDR 的像素节拍。每件的内孔搜索限制在它自己的矩形内，接触该矩形边缘的亮区不能充当内孔。

跨批次用形状、位置、尺寸做一对一匹配，分别保留形状和颜色确认次数。拿走一件导致扫描序号改变时，其他件不会直接继承该序号的颜色。用于静态、手动摆放演示，不保证高速运动、交叉、遮挡过程中的身份跟踪。

首版最多四个候选区域。第五个及以后不处理；不支持的物体也可能占用前四个候选槽，所以测试时请保持背景干净、只放准备识别的零件。内部有溢出标志，但当前简洁界面不显示它。粘连、叠放和轮廓破碎暂不拆分。仍使用 8×8 网格；紧凑螺母／平垫需要约 96 像素以上外形尺度及清楚内孔，微小器件不适合直接缩小演示。

标签相互重叠时优先显示前面的标签，靠近右边缘会向左收回。多目标模式没有新增越线计数、尺寸测量或缺陷检测。旧单目标标量接口只供首槽兼容和诊断使用，尺寸／孔径／运动计数不作为多目标输出；多目标清单才是框和分类的依据。

白平衡校准、相对颜色规则、内部取样均保留。多目标比较能帮助定位问题，不能恢复深阴影或过曝中丢失的颜色。
