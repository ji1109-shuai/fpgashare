# PH1P35 零件视觉识别与传送带控制系统

## 验收版功能与操作说明（screen_menu_v1）

### 1. 系统简介

本系统基于安路 PH1P35 FPGA、SC500CS 摄像头、HDMI 显示器和传送带搭建，面向流水线零件的实时识别、动态跟踪、分类计数与定量停机。

当前验收版支持：

- 摄像头图像实时采集与 HDMI 显示；
- 螺钉、垫圈、六角螺母、四方螺母四类零件识别；
- 黑色、银色、黄铜色等零件颜色辅助判断；
- 最多四个目标的同时框选和动态跟踪；
- 零件从左向右通过检测线时分类计数；
- 四类零件分别设置目标数量；
- 所有已启用类别达到目标数量后，传送带自动停止；
- 传送带停止、50%、53%、56%、60% 五档控制；
- 自动白平衡、白平衡锁定、曝光和增益调节；
- RGB、灰度、Sobel、边缘、二值化、腐蚀、膨胀和卡通化预览；
- 所有主要功能通过显示屏菜单和开发板按键完成设置。

> 图像预览模式只改变显示效果，不改变后台零件识别、跟踪和计数逻辑。

### 3. 硬件连接

#### 3.1 摄像头和显示器

1. 摄像头连接开发板摄像头接口；
2. 开发板 HDMI 输出连接显示器；
3. 检查摄像头排线方向和接口锁扣；
4. 上电后等待摄像头初始化，显示器应出现实时画面和识别界面。

#### 3.2 L298N 与传送带电机

| FPGA 输出 | L298N 端口 | 功能 |
|---|---|---|
| V1 / `O_pwm_v1` | IN1 | 10 kHz PWM 调速信号 |
| V2 / `O_pwm_v2` | IN2 | 固定低电平，确定转动方向 |
| FPGA GND | L298N GND | 共地 |

还需满足：

- L298N 的 ENA 必须保持高电平，通常保留 ENA 跳帽；
- 电机使用外部电源供电，不由 FPGA IO 直接供电；
- FPGA、L298N 和电机电源必须共地；
- 如果传送带方向相反，交换电机两根输出线，不要把 IN1、IN2 都接成 PWM；
- 当前计数方向为零件从画面左侧向右侧运动。

### 4. 开发板开关与按键

#### 4.1 打开/关闭菜单

- `SW4 拨上（1）`：打开显示屏功能菜单；
- `SW4 拨下（0）`：关闭菜单，返回完整检测画面；
- 关闭菜单后，已经设置的图像模式、白平衡、目标数量和电机档位仍然有效；
- 每次重新打开菜单，光标回到 `VIEW`，但各项参数不会因此恢复默认值。

#### 4.2 菜单中的四个按键

| 按键 | 菜单功能 |
|---|---|
| KEY1 | 光标向上移动 |
| KEY2 | 光标向下移动 |
| KEY3 | 数值减小、切换到上一项或执行复位 |
| KEY4 | 数值增大、切换到下一项或执行复位 |

按键采用单次触发方式。按下一次后松开，再进行下一次操作，避免连续误调。

### 5. 显示菜单各项功能

菜单顺序如下：

| 菜单项 | KEY3 | KEY4 | 说明 |
|---|---|---|---|
| `VIEW` | 上一种画面 | 下一种画面 | 选择图像预览模式 |
| `MOTOR` | 降低一档 | 提高一档 | OFF、50%、53%、56%、60% 循环切换 |
| `AWB` | AUTO/FREEZE 切换 | AUTO/FREEZE 切换 | 自动白平衡或锁定当前白平衡 |
| `EXP` | 降低曝光 | 提高曝光 | 调节摄像头曝光值 |
| `GAIN` | 降低增益 | 提高增益 | 调节摄像头模拟增益 |
| `SCR` | 目标数减 1 | 目标数加 1 | 螺钉目标数量 |
| `WAS` | 目标数减 1 | 目标数加 1 | 垫圈目标数量 |
| `HEX` | 目标数减 1 | 目标数加 1 | 六角螺母目标数量 |
| `SQU` | 目标数减 1 | 目标数加 1 | 四方螺母目标数量 |
| `RESET COUNTS` | 清零 | 清零 | 清除四类当前计数并解除完成状态 |

#### 5.1 VIEW 图像模式

`VIEW` 可选择以下八种显示模式：

1. `RGB`：正常彩色画面，建议作为识别验收的主要模式；
2. `GRAY`：灰度画面；
3. `SOBEL`：Sobel 边缘强度画面；
4. `EDGE`：阈值化边缘画面；
5. `BIN`：二值化画面；
6. `ERODE`：腐蚀处理画面；
7. `DILAT`：膨胀处理画面；
8. `CART`：卡通化预览。

建议先用 `RGB` 展示识别和颜色分类，再切换 `GRAY`、`EDGE`、`BIN` 等模式展示 FPGA 实时图像处理能力。

#### 5.2 MOTOR 电机档位

电机档位依次为：

```text
OFF → 50% → 53% → 56% → 60% → OFF
```

- `50%`：最低运行档，带载能力可能较弱；
- `53%～56%`：建议验收档位，兼顾稳定启动和识别时间；
- `60%`：较快档位；
- 显示的百分数是 PWM 占空比，不是闭环测得的实际转速。

#### 5.3 AWB、EXP 和 GAIN

- `AWB:AUTO`：系统持续自动估计白平衡，适合刚上电或光照变化时；
- `AWB:FREEZE`：锁定当前白平衡，适合画面颜色已经稳定后的正式检测；
- 金属零件高光过强、主体发白时，可适当降低 `EXP` 或 `GAIN`；
- 画面过暗、零件边缘不完整时，可适当提高 `EXP` 或 `GAIN`；
- 推荐先保持 `AWB:AUTO`，待画面稳定后再切换为 `FREEZE`。

#### 5.4 四类目标数量

界面使用以下缩写：

| 缩写 | 类别 |
|---|---|
| `SCR` | Screw，螺钉 |
| `WAS` | Washer，垫圈 |
| `HEX` | Hex nut，六角螺母 |
| `SQU` | Square nut，四方螺母 |

计数区显示格式为：

```text
当前计数 / 目标数量
```

例如：

```text
SCR:006/010
```

表示已经检测到 6 个螺钉，目标为 10 个。

特别说明：

- 目标数量设为 `000` 表示该类别不参与自动停机判定；
- 只要设置过的所有非零目标均已达到，系统就判定本批次完成；
- 四类目标可以同时启用，例如螺钉 10、垫圈 5、六角螺母 3、四方螺母 2；
- 四类当前数量会同时显示，不需要切换类别才能查看；
- 目标达到后，传送带自动停止，避免继续送料。

### 6. 完整操作流程

#### 6.1 烧录

1. 开发板上电并连接下载器；
2. 打开 BitWriter，确认左上角不再显示 `No hardware`；
3. 单击 `Refresh`，确认识别到下载器和 FPGA；
4. 单击 `Add`；
5. 添加本文第 2 节所列的 `camera_to_dsi_display_screen_menu_v1.bit`；
6. 选中新添加的 Bit 文件并单击 `Run`；
7. 等待烧录成功，再观察显示器画面。

> 不要误选旧的 `best_result\camera_to_dsi_display.bit`，旧文件不包含当前屏幕菜单功能。

#### 6.2 上电检查

1. 确认显示器出现实时 RGB 画面；
2. 确认电机默认停止；
3. 确认摄像头视野覆盖传送带检测区域；
4. 确认零件运动方向为画面左侧到右侧；
5. 空载观察几秒，确保背景没有被持续误框选。

#### 6.3 设置本批次任务

1. 将 `SW4` 拨上，打开菜单；
2. 移动到 `RESET COUNTS`，按 KEY3 或 KEY4 清零；
3. 分别进入 `SCR`、`WAS`、`HEX`、`SQU`，设置本批目标数；
4. 不需要检测的类别设为 `000`；
5. 将 `VIEW` 设为 `RGB`；
6. 保持 `AWB:AUTO`，待颜色稳定后可切换为 `FREEZE`；
7. 将 `MOTOR` 设置为 `53%` 或 `56%`；
8. 将 `SW4` 拨下，关闭菜单并开始正式检测。

#### 6.4 检测与计数

1. 零件随传送带从左向右运动；
2. FPGA 对零件进行框选、形状分类、颜色判断和动态跟踪；
3. 目标框通过画面中央检测线时，对相应类别加 1；
4. 同一时刻最多可跟踪并统计四个目标；
5. 当所有非零目标数量都达到设定值时，电机自动停止；
6. 完成后可向老师展示四类的“当前数量/目标数量”。

#### 6.5 开始下一批

1. 打开菜单；
2. 执行 `RESET COUNTS`；
3. 根据需要修改四类目标数量；
4. 重新选择 `MOTOR` 的 53% 或 56% 档；
5. 关闭菜单，开始下一批。

> 自动停机后，单独清零不会让传送带突然启动。必须再次选择电机档位，这是本版本的安全设计。

### 7. 建议的老师验收演示顺序

1. **实时显示**：展示摄像头画面能够稳定输出到 HDMI 显示器；
2. **菜单操作**：拨上 SW4，演示 KEY1～KEY4 对菜单的控制；
3. **图像处理**：依次切换 RGB、GRAY、SOBEL、EDGE、BIN、CART；
4. **零件识别**：放入螺钉、垫圈、六角螺母或四方螺母，展示类别和颜色标签；
5. **动态跟踪**：启动传送带，展示检测框跟随零件稳定移动；
6. **多目标能力**：保持零件互不遮挡，演示多个零件同时框选；
7. **分类计数**：展示四类计数同时更新；
8. **定量生产**：设置一个较小目标，例如螺钉 3 个、垫圈 2 个，其余为 0；
9. **自动停机**：零件达到目标数量后，展示传送带自动停止；
10. **下一批复位**：执行 RESET COUNTS，重新设置电机档位，开始下一轮。

---

### 8. 现场注意事项

- 零件之间应保留一定间距，严重粘连或遮挡会降低分类准确率；
- 摄像头、支架和传送带在验收过程中不要随意移动；
- 金属表面反光较强时，优先调节灯光角度，其次再调 EXP/GAIN；
- 正式计数前必须先清零；
- 正式计数时保持零件从左向右通过检测线；
- 电机驱动板必须外部供电并与 FPGA 共地；
- 如果显示器黑屏，先检查是否烧录了本文指定的新 Bit 文件，再检查摄像头、HDMI 和开发板供电；
- 如果电机不转，依次检查 MOTOR 是否为非 OFF、是否已达到批次目标、ENA 跳帽、V1/V2 接线、共地和电机电源。
