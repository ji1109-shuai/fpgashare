# 普通白纸背景与阴影抑制（2026-10-25）

## 现场问题

去掉背光板后，普通白纸上的投影会被原有全局灰度阈值判成前景。宽软阴影可能与零件相连，并把垫圈、六角螺母和方螺母的中心孔填死；因此不是只调白平衡就能解决。白平衡负责中和 RGB 色偏，不能把灰色投影和灰色金属可靠分开。

## 当前实现

生产路径仍为 `user_source/hdl_source/img_proj.v` 中的 `img_tire`，未改视频输出握手或 AWB 像素时序。

1. 保留亮度直方图得到的全局阈值作为“弱前景”。
2. 每个 8×8 单元同时计算 4 bit 局部亮度范围；深黑、红色、黄铜色或硬局部边缘形成“强种子”。
3. 只保留强种子附近两个粗单元内的弱前景，再执行原有 3×3 闭运算。这样可补齐反光金属表面，但软阴影不能沿自身无限扩张并吞并多个零件。
4. 另外保存每个粗单元的 4 bit 亮度。对每个候选只采样中心和上下左右四个环带点，用至少两个方向的中心/环带差恢复被阴影压暗的孔洞。
5. 银色垫圈在阴影下可能出现方形谐波，因此仅在“银色 + 阴影孔洞证据”成立时允许回退到垫圈；实心银色圆仍必须被拒绝。六角和方形螺母继续依靠各自的几何谐波与孔洞证据。

## 新增回归

- `tb_parts_ambient_shadows`：全画幅白纸含轻微纹理/渐变，并为四个零件加入宽软投影；要求连续稳定发布 4 个目标，形状与颜色分别为银色垫圈、红色六角螺母、黑色方螺母、黄铜螺钉。
- `tb_parts_solid_rejection`：先确认银色垫圈，再立即换成同位置实心银色圆；要求不继承垫圈身份且持续不发布。
- 两项已加入 `sim/run_parts_regression.ps1` 默认列表。

2026-10-25 使用 Vivado/XSim 2022.2 的最终功能结果：

- `tb_parts_ambient_shadows`：通过（5 帧，最终连续两帧 4/4 目标）。
- `tb_parts_solid_rejection`：通过（实心银色圆连续三帧 0 目标）。
- `tb_parts`：通过（70 帧尺寸、旋转、缺损、裁切及反例）。
- `tb_parts_multi_no_calibration`：通过（26 帧颜色变化、移除/恢复、溢出、空场、无白板、环境阴影和不支持轮廓）。

## 验证边界与上板建议

功能仿真使用合成形状和数学软阴影，证明逻辑路径和回归约束，不等于真实相机光谱已经覆盖，也不证明 TD 物理时序收敛。新逻辑增加一个每 8×8 单元 4 bit 的亮度 RAM，并增加一次有界形态学扫描；需要用户在 TD 中重新综合、布局布线、检查资源占用和全部时序报告后再生成 bit。

上板时建议使用哑光白纸，避免点状直射灯；光源尽量从相机轴线两侧扩散照明，使阴影边缘柔和。保持已能稳定成像的 EXP/GAIN，先观察四种零件是否分别出框，再记录完整屏幕、EXP、GAIN、WB、REF 和识别延迟。若仍失败，应保存同一摆位下的原图与 OSD，而不是继续只调白平衡参数。

## TD 6.2 RAM 推断修正

首次 TD 构建在布局 25% 报 `PHY-9011`。报告显示 `img_tire` 达到 35,800 LUT / 18,593 REG；根因是 `morph_scratch` 的捕获写和形态学写位于两个独立 `if`，TD 将 14,400 bit 暂存展开为寄存器/选择器。现已合并为互斥的严格单写口 RAM 模板。该改动保持仿真行为不变，修正后环境阴影和实心反例均重新通过。

用户必须从综合阶段重新运行，不能只重试 Physical，否则仍会使用旧的超资源 gate netlist。重新综合后先检查层级面积中的 `g_tire$u_tire`，确认不再出现约 18,593 个寄存器和 35,800 个逻辑 LUT，再运行布局布线。
