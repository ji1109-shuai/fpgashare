# 2.1 整体介绍

系统以安路PH1P35 FPGA为处理与控制核心，由图像采集、成像调节、视觉增强、多目标识别、批次控制及人机交互等模块组成。SC500CS摄像头通过MIPI CSI-2输入图像，FPGA完成数据解包与去马赛克；亮度测光在自动白平衡前独立进行，通过I²C反馈调节传感器曝光及增益，实现亮度收敛与锁定。

白平衡后的图像分为识别和显示两条支路。识别支路完成前景定位、颜色与形状判别及跨帧身份关联，将目标类别、位置和身份信息送入批次控制模块。显示支路完成可调视觉增强及模式选择，经DDR帧缓存后，与目标框、类别标签、计数和运行状态进行OSD叠加，最终通过HDMI输出。两条支路独立工作，使显示增强参数调整不改变识别输入。

批次控制模块结合方向越线与分类配额判定有效计数，并根据完成、错料及超额状态控制电机启停与异常恢复；NG状态同时触发蜂鸣提示。按键和拨码开关通过菜单模块统一配置模式、成像参数、配额及电机档位，FPS与DET统计结果用于在线观察图像输出帧率和识别批次耗时，形成图像感知、规则决策与执行控制相互协同的整体架构。
