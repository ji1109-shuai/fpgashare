# SC500CS 手册精读 03：图像处理算法写在哪里（插入点完全指南）

> 前置：精读01/02（I2C）、FPGA数据流解读。本篇回答："我的算法代码放哪、插哪、怎么插。"

---

## 一、先给另一位老师（AI）的总结补三个代码级锚点

它讲的"窗口化/镜像/倒置/RAW"概念都对，落到这份工程里对应的事实是：

| 概念 | 代码里的事实 |
|---|---|
| 窗口化 Window | **已经在用了**：配置表 0x3208~13 把输出定在 1024×600@(4,4)——起点4就是为了跳过图2-3的4行/4列 Active Border |
| 镜像/倒置 Mirror/Flip | 就是**一个寄存器**：0x3221，bit[2:1]=mirror、bit[6:5]=flip（手册表2-7）。往配置表加一条就能让画面左右/上下翻，**零FPGA资源** |
| RAW10 | 本工程用 RAW10：0x3031=0x0a，DT=0x2B（csi_unpacket 第60行 `FRAME_DATA_DT=8'h2B`） |

**由此得出总原则：能在传感器里做的（几何变换、裁剪、binning），绝不写进 FPGA——那是白送的算力。**

## 二、主战场：流水线插入点地图

```
… → raw10_unpacket (40b = 4×RAW10)
┌─ 插入区A【RAW域】—— 还没有颜色，每个像素只是"某位置的一个亮度"
│    适合：黑电平校正BLC(作者留了槽没接!)、坏点校正、镜头阴影校正、RAW降噪
│    注意：必须按BGGR位置区分像素颜色再处理
└─→ uial2axis → isp_top：
       demosaic(去马赛克, 40b→128b) → data128_96(取低24位→96b) → awb(白平衡, 96b)
┌─ 插入区B【RGB像素域】★新手主战场★ —— 每像素完整{R,G,B}，96bit=4像素
│    适合：灰度化、负片、二值化、gamma(BRAM查表)、亮度/对比度、色彩矩阵
│    特点：纯组合逻辑即可，逐像素独立，无需缓存
└─→ data_96bit_to_128bit(96→128b)
┌─ 插入区C【RGB邻域域】—— 需要"看到邻居"的算法
│    适合：sobel边缘、中值滤波、锐化、腐蚀膨胀
│    代价：要自己造行缓存(line buffer)——骨架照抄 demosaic 的
│        line_buffer_demosaic.v + raw_matrix_3x3_buffer.v
└─→ video_in → DDR2帧缓存 → video_out
┌─ 插入区D【帧域】—— 需要整帧信息的算法
│    适合：电子缩放/平移(改DDR读地址)、画面冻结、帧混合、直方图均衡
└─→ uivtc → hdmi_mixer
┌─ 插入区E【显示叠加】—— 不动图像，往画面上"贴"东西
│    适合：OSD字符/logo/十字线/直方图小窗（参考官方 lab_hd_3_osd 例程）
└─→ hdmi_tx → 显示器
```

**选区口诀**：算法只看单个像素→B；要看邻居→C；要看整帧→D；不改图只叠加→E；还没颜色的原始数据→A。

## 三、插入三条纪律

1. **握手不打折**：tvalid/tuser/tlast 必须和数据同进同出；纯组合变换就全部直通（本链路 tready 直通，无反压负担）；
2. **位宽对号**：RAW域40bit（4×10bit），RGB域96bit = 4×24bit，每24bit内部 `{R[23:16], G[15:8], B[7:0]}`（demosaic 第882行实测）；
3. **分支延迟对齐**：只有"分流"才要对齐（一路算统计、一路直通）——学 awb.v 的 signal_delay 50拍；直通改值无需关心。

## 四、第一个算法作业：RGB 转灰度（字节级精确模板）

```verilog
module my_rgb2gray (
    input  wire [95:0] I_tdata,   // 4像素 × {R,G,B}
    input  wire        I_tvalid,
    input  wire        I_tuser,   // 帧起始
    input  wire        I_tlast,   // 行尾
    output wire        I_tready,  // 对上游的就绪（直通）
    output wire [95:0] O_tdata,
    output wire        O_tvalid,
    output wire        O_tuser,
    output wire        O_tlast,
    input  wire        O_tready   // 来自下游（直通）
);
    assign I_tready = O_tready;   // 纯组合、零延迟、无缓存：最安全的插入方式
    assign O_tvalid = I_tvalid;
    assign O_tuser  = I_tuser;
    assign O_tlast  = I_tlast;

    genvar i;
    generate
        for (i = 0; i < 4; i = i + 1) begin : g_px
            wire [7:0] r = I_tdata[i*24+23 -: 8];
            wire [7:0] g = I_tdata[i*24+15 -: 8];
            wire [7:0] b = I_tdata[i*24+7  -: 8];
            // Y = 0.299R + 0.587G + 0.114B，定点放大256倍
            wire [15:0] y = 8'd77 * r + 8'd150 * g + 8'd29 * b;  // max 65280
            assign O_tdata[i*24+23 -: 8] = y[15:8];  // R=Y
            assign O_tdata[i*24+15 -: 8] = y[15:8];  // G=Y
            assign O_tdata[i*24+7  -: 8] = y[15:8];  // B=Y → 灰度图
        end
    endgenerate
endmodule
```

**接线（改 isp_top.v，两步）**：
1. 注释掉第 36 行 `assign awb_O_tready = O_tready;`；
2. 在 u_awb 和 u_data_96bit_to_128bit 之间插入：

```verilog
wire [95:0] gray_tdata;
wire        gray_tvalid, gray_tuser, gray_tlast;
my_rgb2gray u_my_gray (
    .I_tdata(awb_O_tdata), .I_tvalid(awb_O_tvalid),
    .I_tuser(awb_O_tuser), .I_tlast(awb_O_tlast),
    .I_tready(awb_O_tready),
    .O_tdata(gray_tdata), .O_tvalid(gray_tvalid),
    .O_tuser(gray_tuser), .O_tlast(gray_tlast),
    .O_tready(O_tready)
);
// 把 u_data_96bit_to_128bit 的三个 96b 输入改接 gray_*
```

**文件落位**：`user_source\hdl_source\my_rgb2gray.v` → TD 的 Sources 窗口右键 Design Files → Add Source Files → 重新编译烧录。成功标志：**屏幕变黑白照片**（注意先确认链路本身是彩色的——若插之前就是灰的，说明 demosaic/白平衡有问题，别被自己骗了）。

## 五、进阶路线（每一步都建立在上一步的骨架上）

1. 灰度化（本文，区域B，纯组合）→ 2. 负片/二值化（换个表达式而已）→ 3. gamma 校正（把乘法换成 BRAM 查表，学 IP 的 RAM 用法）→ 4. sobel 边缘（区域C，抄 demosaic 的行缓存骨架——3×3窗口 + 两级行缓存）→ 5. 直方图统计+自动对比度（区域B统计 + 区域D生效，学 awb 的"上帧统计下帧生效"）→ 6. OSD 叠加（区域E，参考 lab_hd_3_osd）。

每完成一个，你就在答辩 PPT 里多一条"自主设计的图像处理模块"。
