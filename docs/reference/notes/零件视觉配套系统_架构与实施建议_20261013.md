# 零件视觉检测与配套计数：架构与实施建议

日期：2026-10-13。依据用户提供的最终任务计划书、最新交接记录、颜色版发布说明及本地《赛题解析二》整理。本文件是设计建议，不代表以下功能已经实现；本轮不改动 RTL。

用户补充：实物零件尚未到来，先参数化设计，器件到来后调整。演示期限尚未确定。

## 1. 最终目标与首版范围

最终成果是一个单路零件检测与配套计数系统：螺丝躺放、六角螺母和平垫圈平放，逐件进入检测区；FPGA 输出类别、可观察的尺寸型号、可见轮廓异常和处理结果；按配方核验实际收集数量。

建议首版使用同一平面、固定镜头和受控光照，每次检测区只有一个完整零件。先以单路分批供料完成混合配套，不要求首版自动从散乱混料中取料。

三类识别、有限型号、少量明确缺陷和实际收集计数构成主路径。三路供料、通用混料、自动封袋列为后续扩展。工业应用提供演示任务，技术成果必须由测量和运行记录证明。

## 3. 当前基础与需要重新设计的部分

|---|---|---|

| RGB 三色分档、有色近圆识别 | 颜色版仿真、实现与位流完成；真实瓶盖效果尚未确认 | 可复用颜色通路与独立演示，不等于金属零件三类识别 |
| 轮胎/瓶盖几何 | 8×8 多数票网格，720p 被降为 160×90 分析 | 可用于粗定位，不作为小零件精密尺寸和缺口依据 |
| 中心与计数 | 现有外接框中心、单目标越线演示计数 | 不等于面积质心、完整跟踪或实际落料核验 |
| 螺丝/螺母/垫圈识别、型号、真实缺陷、SVM、配方闭环 | 未实现 | 需要新的特征、样本和控制流程 |

最新颜色版发布记录：Slice 15174/21216（71.52%），ERAM 60/108，DSP 16/40；布线 SWNS +0.100 ns、HWNS +0.020 ns，当前 STA coverage 94.62%。这些是现有约束下的基线，不保证新增模块后仍满足时序，也不能把 Slice 比例直接当 LUT 比例。

改造策略：保留视频/显示与必要的粗定位，在主项目中替换不再适用的轮胎专用分类逻辑。旧位流继续保留，避免把全部旧算法和新算法长期叠加后消耗资源。

## 4. 推荐架构

视频主链路保持连续：

`MIPI → ISP → 视频缓存/HDMI → OSD`

识别支路从同一帧图像取样：

`白板粗定位或已标定检测区 → 板内细分割 → 特征累加/必要的局部二值缓存 → 类别 → 尺寸型号 → 外观检查 → 检测事件`

控制支路：

`检测事件 + 配方 → 放行/剔除安排 → 落料核验 → 实际数量更新 → 配套完成/故障`

显示模式只改变画面，不应悄悄改变识别输入。识别可以低于显示帧率，但需要测量完整确认延迟和允许的物体间距。每份特征和结果携带帧号、配置版本及有效标志；图像和结果之间的延迟应明确，尤其在目标运动时。

白板粗边界用于屏蔽板外黑背景。在其安全内区提取原分辨率或更细尺度的物体轮廓；板边附近需要精细复核或留明确定义的有效检测区，避免再次把量化边界误当截断。

单目标约束最好由供料间距和检测触发帮助保证。不能仅凭“最大连通域”证明只存在一个物体；完全接触的重叠件也不一定能从单视角可靠判断。

## 5. 先解决看清，再决定分类算法

### 成像与尺度

- 背光主要提供外形和孔洞；需要颜色时另加适度漫射正面光，并检查补光是否破坏轮廓分割。
- 固定相机高度、焦距、工件平面和曝光条件。改变相机高度后重新标定。
- 先定义希望检出的最小缺陷，再检查其在图上有多少像素。若尺度为 k 像素/mm，尺寸 d mm 对应约 kd 像素；仅占 1～2 像素的缺口无法作为可靠缺陷承诺。
- 软件模拟不同分辨率后再定硬件缓存。提高显示分辨率不自动解决物体在视野中占比过小的问题。

### 特征与三类判据

| 类别 | 优先验证的特征 | 需要避免的误判 |
|---|---|---|
| 螺丝 | 二阶矩细长程度、长度、头部/杆部宽度变化；必要时沿主轴的宽度分布 | 旋转后轴对齐外接框长宽比会变；细长物体不能直接都叫螺丝 |
| 六角螺母 | 中心孔、外轮廓六边形特征、对边尺寸、孔与外形比例 | 二阶矩接近各向同性，单靠矩和孔洞不一定能与垫圈分开 |
| 平垫圈 | 单主孔、外轮廓圆度、内外轮廓比例和同心程度 | 外接框近方、存在孔洞不能单独证明是垫圈 |

第一批公共特征建议为面积、真实质心、外接框、二阶中心矩、孔特征、外轮廓圆/六边形区分特征。轴向宽度分布先在软件验证收益，再决定硬件实现方式。

面积需要注明是金属前景面积还是孔洞填充后的外轮廓面积。背光下内部可见孔形不一定等于机械公称孔径，尤其螺母有倒角和螺纹，必须按实际成像标定。

优先使用流水累加与帧末计算单元复用；除法、开方、角度计算只在确实需要时加入。二阶矩可先用不显式求角度的旋转不变指标分类，主方向箭头的显示可以另用近似运算。

### 规则、SVM 与 CNN 的选择

先建立能解释错误的规则基线，同时导出特征。实物到来后按实物/拍摄批次划分数据，比较规则与线性 SVM。相同特征下，若 SVM 并未改善独立测试结果，就不为算法名称增加复杂度。

三类、约十个特征的线性 SVM，只需约三十次乘加完成一次三分类评分，可以用复用计算单元逐项执行。需核算定点位宽、归一化、累加溢出和实际调度；其低计算量不能替代真实样本的可分性验证。

CNN 是将来针对纹理或复杂外观问题的候选。当前先验证几何信息是否足够，片上余量不足以直接证明某个 CNN 可部署；任何候选都应列明权重、激活缓存、计算量及实现时序后再评估。

## 6. 型号、缺陷与合格状态分开

类别回答“是什么”；型号回答“是否符合目标尺寸范围”；可见缺陷回答“在观察范围内是否异常”；最终放行还取决于配方需要和检测有效性。

首版型号用可测量的外观规格标识，例如某长度与头部尺寸组合、某外径与孔形组合。俯视轮廓相同但螺距、厚度、材质不同的零件，不应承诺仅用该视图区分。

先覆盖尺寸超差、明显缺口、明显弯曲和孔形异常。各项都需要正常样本和真实异常样本定义阈值。合成异常只验证计算逻辑，不能证明真实缺陷检出率。

输出建议分字段：`valid / class / size_id / quality / reason / frame_id / config_version`。低分、特征不足或未标定应输出待复检/未标定，不得用最高分类分数直接宣布合格。

## 7. 参数化的具体边界

| 层级 | 内容 | 修改方式 |
|---|---|---|
| 硬件结构参数 | 最大 ROI、缓存深度、队列深度、位宽、支持特征、视频格式 | 通常修改后重新综合与布局布线 |
| 运行配置 | ROI、安全边距、阈值、最小面积、尺寸标定、型号区间、配方数量、触发延时/距离、超时 | 预留配置寄存器；可从按键或串口等接口装载 |
| 数据与模型 | 特征定义版本、归一化、SVM 权重/偏置、拒识门限、正常范围 | 真实采样后建立和验证，再装载或编译进设计 |

暂定值必须标记为调试值。建议设置 `calibrated` 和 `model_valid` 标志：未完成标定/模型验证时可以显示特征和候选结果，但不作为尺寸合格放行依据。

配置应成组更新，在帧或检测周期边界生效。每次检测和后续控制绑定所用配置版本；配方改变时明确处理在途物体，避免旧判据和新订单混用。最终固化设计包含可独立启动的默认配置。

二值缓存估算：256×256 约 8 KiB，512×512 约 32 KiB；1280×720 单帧约 112.5 KiB，双帧约 225 KiB。实际还要考虑 ERAM 打包、端口、队列及现有模块占用，不能只比较理想字节数。局部 ROI 若依赖本帧定位，要明确下一帧采集还是先缓存，否则“先找框再取本帧框内像素”存在因果问题。

逐像素统计可在约定的单目标固定检测区进行，避免定位后才能开始的依赖；复杂孔/轮廓算法按需要使用局部缓存。先用软件确定必要特征与分辨率，再冻结硬件上限。

## 8. 配套计数的最小完整闭环

先限制单路、低速、分批供料，必要时每次仅允许一个在途零件。这样容易将视觉结果与实际落料脉冲对应，也容易验证剔除动作。

每个检测事件保存事件号、类别/型号、处理状态、配置版本和预期执行位置。需要多件在途时增加队列；恒速延时仅适用于已验证的速度条件，变化明显时改用编码器或位置传感器。

落料传感器只能确认经过，通常不能识别类别，必须与已放行事件匹配。原始传感器信号需同步、滤抖并形成单次事件；两件连落不能默认是一件。

配方需区分：视觉合格数、剔除数、实际核验收集数、已放行但未核验的在途数。停止放行的判断应考虑实际数与在途数，避免最后一件尚未落下时又放进下一件。全部目标数量核验完成且没有未处理在途事件，才产生配套完成。

无预期事件却出现落料、预期落料超时、数量超出、队列溢出或卡料时进入故障，停止继续投料；不得静默补计。首版可人工摆放或辅助供料，但实际收集闭环必须如实说明其自动化范围。

## 9. 分阶段交付与验收

| 阶段 | 交付 | 验收依据 |
|---|---|---|
| A：可观察的分析平台 | 当前接口/时钟审核、可配置检测区、细尺度分割、特征输出、软件参考、资源基线 | 合成图和仿真逐项核对；此时不宣称真实识别准确率 |
| B：真实三类与有限规格 | 实物采样、尺度标定、规则与 SVM 比较、型号/可见异常/待复检 | 按实物或批次隔离的测试；移动旋转、反光、截断及失败样本记录 |
| C：单路动作与实际计数 | 检测事件、放行/剔除、落料核验、重复/超时与在途管理 | 一物一事件，不串位；视觉计数和实际数量对照 |
| D：配方演示与固化 | 可改配方、单路分批配套、完成/故障、统一显示模式、上电运行 | 实际收集数量与配方一致；断电重启；持续运行；所有功能在同一最终镜像 |

基础显示、接口延迟和资源时序检查贯穿每阶段。每次 RTL 改动运行相关仿真，结构变化后增量检查综合/实现；不等全部算法堆好才第一次检查是否装得下。

## 10. 零件未到时可以推进的工作

1. 完成工程接口和当前数据路径审核，记录每拍像素数量、帧行标记、RGB/二值对齐、CDC 与时钟约束。
2. 定义特征字段、运行配置、结果状态和检测事件接口；暂定参数与真实标定参数明确区分。
3. 建立软件参考与旋转、移动、孔形、缺口等合成输入，比较候选特征和所需分辨率。
4. 设计细尺度分割/累加模块，优先提供可导出特征；为实物到来后采集与调参准备工具。
5. 使用仿真事件验证配方与落料状态机，包括重复脉冲、超时、在途超量和异常中止。

实物到来后：确认最小工件/缺陷像素尺度 → 固定光照和姿态条件 → 标定 → 采集数据 → 定阈值/决定模型 → 板级验证。调整参数可以减少返工，但真实外观导致特征无效时仍可能需要修改算法。

## 11. 结论

方案有可实施的主线。关键是精细且可测量的成像与特征、有限且可区分的样本范围，以及将每次识别真正对应到实际收集数量。现有视频基础有复用价值；现有轮胎网格与计数规则不能代替新的零件分析和配套闭环。

下一步建议从阶段 A 的接口、特征和参数设计开始。最终结构不预先绑定 SVM 或 CNN，实物验证后选择达到目标且占用合理的分类方式。
