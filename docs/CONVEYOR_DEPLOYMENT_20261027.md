# 白色输送带零件识别部署方案（2026-10-27）

## 结论

现有普通照明版针对平滑白纸和宽软阴影设计，不能直接等同于白色织纹输送带。输送带的纤维纹理、接缝、侧边和运动模糊会同时破坏全局二值化、8×8 局部边缘种子及孔洞判断。后续不再只调一个灰度阈值，而是先固定成像条件，再增加粗网格空带参考。

## 必须先固定的成像条件

1. 摄像头光轴垂直输送带，支架锁紧；画面只保留皮带中央检测区，避免侧轨、桌面和电机进入识别区域。
2. 最小待测螺母的外径在 1280 像素画面中应达到约 110～180 像素。当前分类器对紧凑零件至少要求约 12 个 8×8 单元，即 96 像素；尺寸再小会在进入分类前被拒绝。
3. 不使用原可调背光板。改用固定亮度、左右对称的漫射顶光或低角度条形灯，并用遮光罩隔离实验室顶灯。灯前加乳白扩散片，避免单点强反光。
4. 若允许改输送带表面，优先在检测段使用哑光蓝色连续带面。蓝色与银、黄铜、红、黑四类均有可用亮度或色度差，比白色织纹带更稳定。不要使用亮面胶带或只贴一块会周期性经过视野的短贴片。
5. 金属高光仍过强时，可在灯和镜头前加互相旋转 90° 的偏振片进行交叉偏振；增加照度补偿偏振造成的光损失。

## 运动条件

- 先停带验证单件静态识别，再以最低速度验证跟踪，最后逐级提高速度。
- 运动模糊目标不超过 1～2 像素。若检测区横向视野宽度为 `F` mm，皮带速度为 `V` mm/s，则建议曝光时间满足：`T <= 2*F/(1280*V)` 秒。
- 屏幕 `DET` 是一次识别批次的内部耗时。零件完整停留在有效检测区的时间至少取 `3 × DET`，以留出连续帧确认和位置关联时间。
- 零件间距至少大于最大零件外径的 1.5 倍，初版不处理接触或重叠件。

## 下一版轻量算法

受当前资源限制（2026-10-25 构建：Slice 94.73%、ERAM 69.44%、最终 SWNS 0.100 ns），不增加整帧 RGB 背景缓存。计划复用现有 160×90 的 8×8 粗网格：

1. 用 SW4 进入空带学习状态；空带运行约 2 秒，逐单元学习亮度中心、纹理范围和允许波动。
2. SW4 关闭后冻结参考。当前单元只有在偏离空带范围并获得颜色或硬边缘支持时才进入前景，皮带织纹不再仅因局部亮度范围大就成为强种子。
3. 保留现有有界闭运算、连通域、孔洞及形状分析；形状使用背景差分掩膜，颜色只在目标内部收缩区域投票，减少白带混入银色票。
4. 仅在画面中央固定检测门内确认类别；目标沿输送方向关联，越过输出线后只计数一次。
5. 空带学习期间禁止发布目标，避免把学习中的皮带接缝误计为零件。

## 修改前需要采集的现场数据

保持相机位置、灯光和 EXP/GAIN 不变，记录以下画面：

1. 空输送带停止：RGB、BIN、EDGE 各一张。
2. 银色六角螺母停止在画面中央：RGB、BIN 各一张。
3. 同一螺母以最低速度通过：RGB 一张，能看清 EXP、GAIN、DET。
4. 记录皮带速度，或记录零件通过 20 cm 距离所需时间。

这组数据用于确定织纹的粗单元波动、零件像素尺寸和允许速度。没有这些数据就继续放宽阈值，会在“漏检金属”和“整条皮带被识别”之间反复摆动。

## 第一张输送带实测画面

2026-10-27 单个大尺寸六角件置于织纹皮带，RGB 画面中未出现确认框。屏幕数据为 EXP=2244、GAIN=112、WB=AUTO、DET=16.3 ms，颜色诊断约为 `R=0000、S=0034、Y=0000、K=03A5、N=0408、WHY:OK`。

据此可排除两项：零件像素尺寸不足和处理速度不足。候选区域已有约 0x408 个粗单元参与统计，颜色统计也已完成；没有确认框更可能是 `class_ok` 前的孔洞/外形条件失败。该金属件在当前照明下约 90% 的有效颜色单元被判成黑色，银色证据只有约 5%，说明白带曝光压暗了金属主体，当前光照也不足以稳定区分银色与黑色。

画面中的内孔区域与金属主体同为深灰，皮带织纹在孔内基本不可见，现有中心/环带亮度差恢复条件很可能无法成立。下一步仍需同一摆位的 BIN 与 EDGE 画面：BIN 用于确认孔是否被填实，EDGE 用于确认内圆边界是否连续。得到这两张后，再决定采用空带差分恢复孔洞，还是为六角/方形件加入受约束的外轮廓回退；不直接取消所有孔洞条件。

### 已实施的第一步回退

用户要求直接修改后，生产分类器增加受约束的暗孔回退：仅当候选具有稳定六角或四方外轮廓、孔洞面积不足、中心/环带对比也失败、整件颜色为黑色，同时仍有至少16个且不少于总面积1/32的中性高光单元，并且没有红/黄铜票时，才允许按六角/四方螺母发布。实测的 `S=0x34、N=0x408` 满足该反光证据门限。

垫圈仍必须具有孔洞或中心/环带对比，避免把实心圆盖误报为垫圈；均匀纯黑的实心六角形也不触发本回退。该修改只解决“金属螺母内孔被暗影填死而不出框”，不会把当前 `K` 占优的颜色强行改成银色。

新增 `tb_parts` 用例：纯黑实心六角形连续拒绝；同一外形加入按粗单元分布的中性反光后，按暗孔六角螺母确认。Vivado 2022.2 `xvlog` 已通过生产 RTL 和测试源的静态分析。当前 Windows 会话中的 Vivado 自带 MinGW 报“无效的系统 DLL 重定位”，导致 `xelab` 无法编译生成的 C 文件，连未改动的小型形状测试也同样失败；因此本轮尚无完整 XSim 运行结论，也未运行 TD 综合/布局布线。

## 2026-10-27 已撤销试验：空带学习与背景差分

> 当前生产源码不再包含本节算法。本节仅保留试验记录。小组决定把背光板安装到传送带下方，恢复高对比轮廓判定；背景RAM、SW4学习接线、背景测试和对应时序试验均已撤销。

现场把照明调到最高仍不出框，证明继续打磨全局二值阈值没有意义。生产识别入口已改为以下流程：

1. `SW4=1` 时进入空带学习。学习期间输送带必须运行、检测区不能有零件；系统不发布目标。
2. 160×90 粗网格的每个 8×8 单元保存一个8位参考：空带多帧中最低亮度中心值和最大局部纹理范围。织纹随皮带移动造成的正常波动因此被包进参考范围，不需要整帧图像缓存。
3. `SW4=0` 后冻结参考。当前单元比空带参考更暗，或局部纹理范围超出参考时，才进入弱前景；更大的偏差、硬边缘或材料颜色证据成为强种子。弱前景仍须位于强种子附近，避免皮带小幅波动无限扩张。
4. 有有效空带参考时，形状掩膜和颜色采样不再依赖全局二值阈值；没有参考时才回退到原有阈值路径。背景差分之后继续复用闭运算、连通域、孔洞、形状分类和跨帧跟踪。
5. SW4在自动白平衡模式下原本不冻结增益，因而可安全复用为背景学习开关；手动白平衡模式的历史操作不适用于本生产配置。

至少4个完整学习帧后参考才有效，现场建议空带运行并保持SW4打开约2秒，再关闭SW4放入零件。相机、灯光、焦距、机位或输送带表面发生变化后必须重新学习。

粗网格背景模型容量为 `160×90×8=115200 bit`，约6个20 Kbit ERAM，不增加1280×720整帧缓存。上一次资源报告尚有33个ERAM余量，但LUT已很紧；是否成功映射为ERAM、最新利用率和时序必须以用户重新运行TD后的报告为准。

新增 `tb_parts_conveyor_background`：空带纹理随帧移动，学习帧不得出框；冻结参考后强制把全局阈值设到无法提供零件前景的数值，仍要求背景差分恢复银色六角螺母。Vivado 2022.2 `xvlog` 已通过全部零件RTL和测试源的静态编译；`xelab` 完成静态展开和数据流分析后仍因本机既有的生成C文件编译故障终止，因此不能声称完整功能仿真通过。本轮未运行TD构建。

### 首次TD构建与时序修正

用户于2026-10-27完成首次背景学习版TD构建。背景模型已正确映射到ERAM：ERAM由历史75个增至82个，仍低于108个上限；物理报告为LUT6 19562/21216（92.20%）、Slice 20050/21216（94.50%）、REG 16388、DSP 20。该构建只有两个MIPI_RX_BYTE_CLK setup端点违例，SWNS=-0.033 ns、STNS=-0.065 ns，HWNS=+0.020 ns。

报告定位到两条组合路径：一条从形态学坐标经地址选择、`morph_scratch`分布式RAM读取到`morph_q`，最大扇出2059；另一条从队列ERAM输出经`board_rows`异步读取、左右边界比较回写到行边界RAM。曾为这两条路径加入流水寄存；随着整个背景差分试验撤销，这两处未上板验证的时序改动也一并撤销。恢复版需要重新运行TD，以新报告确认SWNS/HWNS均非负。
