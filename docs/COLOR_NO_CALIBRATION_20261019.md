# 取消前置白平衡校准和锁定

**现场失败，已撤回：用户反馈固定1倍后画面变绿。下文使用步骤、固定增益与测试结果仅记录当时实验。当前代码改为自动估计并保持有效白平衡，见 [AUTO_WB_20261019.md](AUTO_WB_20261019.md)，不再使用本实验的固定增益配置。**

2026-10-19。用户反馈上一轮黄铜误判红色、黑色未知，要求撤除白纸校准/SW4 锁定机制。本次按此要求修改当前合作工程，没有运行 TD 构建或生成 bit。

## 当前行为

- 上电直接检测，不放白纸，不等待 REF，不操作 SW4 锁定。SW4 对当前零件版本的图像与颜色识别无效。
- 图像的 R/B 补偿从复位起固定 1 倍，G 直通。保留原 AWB 的数据延迟与提前帧头；没有用直连导线替换流水线，也没有改回随画面内容变化的自动白平衡。
- 识别端不再因参考无效、未锁定、曝光/增益改变而禁止颜色。显示端同时取消参考门控，不再将已识别的颜色强制显示为 UNKN，移除 WB/REF 校准诊断文字。
- 仍有实际颜色证据不足而输出 UNKN 的情况；取消校准不等于强行给每件物品分配颜色。
- 上一轮实验的红色范围放宽、中性色范围收窄及反光优先投票已撤回。`img_proj.v` 恢复合作仓库基线 `4f32b30` 的规则，仍采用颜色比例、8×8 小块投票和目标/跨帧确认。当前黑/银亮度参考为常量 224，与白纸无关。
- 白色背板检测和分割自适应、四目标、形状确认、安路图标、已确认目标框、颜色/形状标签及手动曝光/增益控制保留。没有修改传感器寄存器配置。

源码入口是 `td_project/camera_to_dsi_display.al`。顶层 `design_top_wrapper.v` 将 `COLOR_STABILITY`、`COLOR_DIAGNOSTICS`、`WB_DIAGNOSTICS` 关闭；`isp_top.v` 在零件无校准模式下固定保持复位时的单位增益。底层校准代码保留为历史显式启用/回归功能，当前生产配置不执行该流程。

## 使用步骤

1. 用户在当前仓库工程自行综合、布局布线，检查全部时序报告，再生成并下载新 bit。原有 bit 不会因编辑源码而改变。
2. SW1/SW2/SW3 全关观察 RGB；SW4 任意。直接使用背光板和零件，不放白纸，不做锁定。
3. 先保留此前能稳定框选的曝光/增益、灯光及相机高度，将红、黄铜、银、黑色零件分开放置后同屏观察。需要调节时继续使用既有 EXP/GAIN 操作，无需重新校准。
4. 如需反馈，只需整屏照片、真实物件颜色及 EXP/GAIN；先看 RGB 是否接近实物，再看标签。照片中尽量包含四种零件，便于同一光照条件下比较。

## 功能验证

新增三项回归：

- `tb_parts_no_calibration_isp`：真实 AWB/ISP，1280×720、每拍四像素，逐拍核对图像不被补偿或重排；覆盖从上电开始的单位增益、跨帧和帧内 SW4 切换、EXP/GAIN 状态更新、提前帧头和行/帧有效数据总量。
- `tb_parts_multi_no_calibration`：无有效参考、ready 从上电为 0 时识别四种颜色/形状；改变 ready/epoch，含分析中途改变，不清空颜色；同时核验移除、换序、溢出、无背板与不支持轮廓。
- `tb_multi_overlay_no_calibration`：参考全为 0，逐像素核验四个独立标签、安路图标和 EXP/GAIN，确认不再画校准状态、候选框仍隐藏。

基线颜色回归新增人工反例：`RGB=(200,176,152)` 不应因放宽阈值误判红色；`RGB=(40,38,32)` 应保留黑色。这是合成样本，不是用户摄像头实测值。

运行方法见 `sim/README.md`。本轮结果记录在 [COLOR_NO_CALIBRATION_RESULTS_20261019.txt](COLOR_NO_CALIBRATION_RESULTS_20261019.txt)。

本轮 26 个功能测试顶层全部通过：颜色/ISP/OSD 13 项、零件 5 项、视频/DDR 8 项。新增 ISP 测试核对 921600 个 RGB 有效拍保持原值和顺序，四帧输出 691200 个打包拍、2880 行；Sobel/EDGE 连续帧与 DDR 地址检查通过。

## 验证边界

仿真中的去马赛克及厂商 RAM 含替身，不能证明真实传感器输入、照明、物理时序或现场分类准确率。取消白平衡不会修复输入本身的色偏，也不能恢复已过曝而丢失的物体颜色。本版首先撤除用户明确拒绝的前置流程和失败实验；不声称已解决所有颜色问题或已支持绿色流水线。
