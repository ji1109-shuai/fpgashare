## 新目标与锁定规则

- 默认亮度中心从旧区间中心196降为**128**，默认允许范围**112～144**。
- `AE Y`可在**64～192**间调整，**步长8**；允许范围始终为所选目标±16。
- 连续**16个完整有效测光包**达标才LOCK；空等时钟、无效包、未完成配置及I2C忙时不能充数。
- 实际I2C完成后仍丢弃2个有效测光包，等待N+2。连续4包在同一侧超范围才调整参数。
- LOCK后停止自动写入。处于AUTO/LOCK时改`AE Y`会清除旧锁定及累计次数，按新目标重新收敛，无需手调EXP/GAIN。
- 显式MAN不会被目标编辑强行改回AUTO；直接编辑EXP/GAIN仍进入MAN。
- 目标是当前AWB前空间75百分位测光值，不是零件表面平均亮度，也不保证任意背景/照明都具有相同视觉效果。

## 操作

1. SW4打开菜单，KEY1/KEY2移动到最后一项`AE Y`（RESET COUNTS之后）。
2. KEY3降低目标，KEY4提高目标；数值越小，目标画面越暗。
3. 菜单关闭后目标保持；复位/断电后恢复默认128，不做非易失保存。
4. 屏幕应显示本轮版本`AE3:AUTO`，达标后为`AE3:LOCK`及`S:16/16`。

调整步长8小于稳定容差的总宽度32。如果只调一档，而当前测光仍在新目标±16范围内，控制器会重新完成16次确认，但不强制改变曝光；若画面仍亮，可继续降低目标，例如由128调到112或96。这样保留稳定区，避免为了单档差异反复抖动。

左侧三行示例：

```text
AE3:AUTO Y:88 V1
I:11 W:05
T:128 S:07/16
```

`T`和菜单目标为十进制；`Y`为十六进制实测值，默认允许区间112～144对应`70～90`。
`I`为初始化/配置完成，`W`为完成的运行时写入数（十六进制）；ACK及完成信号不等于传感器寄存器读回。
保留图标、确认目标框与标签、批次计数和其他菜单功能；菜单仅增加一行。
