# 自动白平衡与偏绿修正

2026-10-19。用户反馈固定 R/B=1 倍的版本下载后画面变绿，最终明确要求停止回退、继续解决偏绿。当前修正针对图像白平衡通道；现场是否改善仍需用户自行构建并上板确认。

## 已确认和未确认的原因

固定单位增益会让相机去马赛克后的 RGB 原样通过，不能消除输入本身的绿色偏差。更早的中心64×64手动参考模式，在中心被零件覆盖、参考过曝或锁定无效时，会拒绝样本并回到单位增益。同一合成偏绿背景 `(128,192,128)`、中心红色物体可复现：这两种配置都保持绿色，新自动配置能将中性背景输出修正到约 `(192,192,192)`。这是可核验的软件机制，不能据此宣布真实传感器/RAW输入/光源的全部根因已定位。

新增测试使用真实生产BGGR双线性插值模块，对256级中性灰和256种彩色Bayer块、两种行奇偶和四个像素通道逐项检查，没有发现这些输入被插值额外放大绿色。但该测试没有覆盖真实MIPI数据排列、全部行缓存和物理板输入；不能因此完全排除硬件RAW相位或输入问题。

## 当前代码行为

1. AWB自动统计整幅图像的候选中性像素，每拍抽像素0；各通道必须为64～240，最大通道不超过最小通道两倍，避开暗区、明显有彩色和过曝通道。每帧至少1024个合格抽样才估计G/R、G/B。这是候选筛选，不能保证识别出物理上真正中性的材质。
2. 沿用原串行除法和1/4步长平滑，工作增益只在帧头更新，整帧恒定。没有增加像素数据流水级，没有改变提前SOF、行数据量、DDR接口和Sobel/EDGE时序。
3. 没有合格样本时保留最近有效的补偿。上电从未得到有效样本时，保持初始单位增益并显示WAIT；不会虚构光源颜色，也不会把过曝当作校准成功。
4. 不要求白纸、手动校准或SW4锁定。SW4和曝光/增益状态事件不再清空自动补偿；光照/参数变化后，遇到合格样本会继续估计新的比例。没有样本时旧补偿可能不再适配新的光源，HOLD不能解释成新光源校正已通过。
5. 颜色识别及显示不再受手动锁定状态门控。保留原基线形状/颜色规则、白背板分割、四目标确认框和安路图标，没有恢复失败的颜色阈值/反光投票实验，也没有实现HSV分类。

当前方案针对白色背光板和分离摆放零件，假设有足够未过曝中性区域。不是任意背景/任意照明下的颜色恒常算法；全图中其他类似中性色的表面也可能参与统计。底部背光与物体正面环境光的光谱仍可能不同，消除背景偏绿不等于物体颜色分类已经准确。

## 使用和回传

1. 在本仓库 `td_project/camera_to_dsi_display.al` 中自行综合、布局布线，检查完整时序报告后生成并下载新bit。助手没有运行TD构建。
2. SW1～SW3全关观察RGB，SW4任意。先保持之前能稳定框选的EXP/GAIN、灯光和高度，不放白纸，不执行锁定。放置零件时保留可见背板区域。
3. 等待约1～2秒，观察图像及诊断。`WB:AUTO` 表示已有自动解、最近一帧也有足够候选样本；不等于增益已经收敛或真实颜色已正确。`WB:HOLD` 表示暂时缺少样本，保留先前补偿。`WB:WAIT` 表示从未得到有效解。
4. `RAW`仍是**补偿前**画面中心64×64的RGB均值；`R`、`B`是实际使用的补偿，十六进制Q12，1000为1倍。其他OK/HI/LO/CAST/SMP也只描述中心区域；自动增益估计覆盖全图，因此中心被零件覆盖时SMP可显示CAST，而WB仍为AUTO，这是两个不同范围的状态。
5. 若仍偏绿，请回传一张完整屏幕照片，让RAW、R/B、HI/LO/CAST、WB和EXP/GAIN可读，同时说明是均匀偏绿还是绿紫交错/条纹。无需先放白纸。这些信息能区分“没有可用样本”“已补偿但输出仍偏色”和“RAW输入/像素排列异常”。

如果持续WAIT且中心HI很高，意味着观察区可能已过曝；实际检测平面需要留有未过曝中性区域，软件不能从全饱和区域恢复通道比例。不要因为图标/OSD白色正常就把相机RGB看成已中性，两者是不同的图像来源。

## 源码和验证

- `awb.v` 新增显式 `AUTO_REFERENCE` 模式，保留历史手动模式的默认语义。
- `isp/isp_top.v` 新增 `AUTO_WHITE_BALANCE`；当前顶层开启自动模式，关闭手动 `COLOR_STABILITY`。
- `hdmi_mixer.v` 对应自动状态文字，解除以手动锁定状态压制目标颜色的逻辑。原图标与目标叠加保留。
- 主要新增测试：`tb_awb_auto_reference`、`tb_bayer_neutral`、`tb_auto_wb_isp`、`tb_auto_wb_overlay`、`tb_parts_multi_no_calibration`。历史白平衡/OSD回归和视频/DDR回归继续执行，入口见 `sim/README.md`。

结果见 [AUTO_WB_RESULTS_20261019.txt](AUTO_WB_RESULTS_20261019.txt)。有些测试使用厂商RAM或去马赛克替身；真实BGGR插值另有独立测试，不代表整个传感器链路已仿真覆盖。功能通过不能作为物理时序或上板颜色验收。

本轮24个独立测试顶层全部通过：颜色/ISP/OSD 15、视频/DDR 8、四目标1。实际尺寸ISP核验1382400个RGB有效拍、1036800个打包拍和4320行。修正单独保存为本地Git提交，明确待上板验证；未自动推送。
