# 黄铜颜色现场诊断（2026-10-22）

本次为诊断版，只临时开启颜色统计 OSD，并显示目标裁剪标志；没有改变颜色分类、自动白平衡、曝光/增益控制、像素延迟或视频/DDR路径。收集现场数据后，再决定是否增加高光过滤或背景参考补偿。

## 屏幕字段

- `WB`: 自动白平衡状态。
- `REF`: 当前自动白平衡模式下，全画面合格中性候选像素的白平衡前 RGB 均值，按 R/G/B 六位十六进制显示。它是筛选后的候选均值，不是固定中心区域或完整背景的均值。
- `RGB`: 当前已确认目标的稀疏前景 RGB 均值。诊断采样每个 8x8 区域取一个点，受目标位置、孔洞和亮暗区域分布影响，不等同于全表面均值。
- `R/S`: 当前目标红色/银色网格票数，十六进制。
- `Y/K`: 当前目标黄铜色/黑色网格票数，十六进制。`Y` 为颜色像素分类票数，不代表材料检测结果。
- `N`: 目标有效颜色网格数，十六进制。
- `CL`: 单目标分支中，目标诊断稀疏样本至少 1/4 有任一 RGB 通道达到 250 时为 `1`。当前生产多目标分支尚未连接此标志，高部写零；因此当前 `CL=0` 不能证明目标没有高光或通道裁剪。补齐连线并验证后才能用它指导调整。
- `F`: 是否回退到目标外层样本（`1`）或已采用足量内部样本（`0`）。
- `WHY`: 现有颜色输出的原因码。

这些数值是相机/逻辑处理链路中的统计值；手机拍屏颜色不能作为 RGB 真值。中心64x64区域对应另一条白平衡诊断RAW字段，当前此诊断窗口未显示该字段。

## 采集步骤

1. 在 `D:/fpgashare/td_project/camera_to_dsi_display.al` 构建本次诊断版。曝光、增益、照明和相机高度保持当前能稳定框选的设置；SW1-SW3 保持 RGB 原图模式，SW4 不承担白平衡锁定。
2. 单独放黄铜螺母，置于白板内，等待标签和统计稳定后拍摄完整屏幕。记录真实物品、标签、EXP/GAIN、`REF`、`RGB`、`R/S`、`Y/K`、`N/F` 和 `WHY`；当前多目标CL字段暂不作为判断依据。
3. 用相同位置、设置和照明换成银色零件，再拍一张。
4. 若这两组数据显示有效颜色票不足，再针对一件黄铜螺母仅改变背光亮度，记录变化前后数据。其余条件不变。

先提供黄铜和银色两张完整屏幕照片即可；单独摆放一个目标能避免当前诊断窗口取到其他目标。此数据用于判断候选中性参考和目标统计是否稳定；判断高光仍需补齐诊断或其他数据。不要仅依据本诊断版判断颜色已修复。
