# FPGA 零件智能视觉定额备料系统

基于安路 PH1P35 FPGA 与 SC500CS 摄像头的工业零件视觉识别和输送控制原型，集成图像采集、成像调节、多目标识别、分类计数、批次配额、输送控制及屏幕交互。

本目录整理自当前整机工程。历史文档中的参数、路径与旧版功能以当前源码及下列最新说明为准。

## 主要功能

- 1280×720 图像采集处理与 HDMI 显示，DDR 帧缓存。
- 自动曝光优先调整曝光时间，配合增益边界补偿；默认亮度目标152±8，连续16个有效测光包达标后锁定，目标可调。
- 自动筛选候选中性像素进行白平衡；样本不足时保持最近有效补偿。
- 原图、灰度、Sobel、边缘、二值及形态学预览；工业增强支持细节强度、噪声门限及原图/增强对照，模式7为ENHN。
- 螺丝、垫圈、六角螺母、四方螺母多目标识别及颜色/形状标签。
- 跨检测批次身份关联与方向越线计数；分类配额完成停机、错料/超额保护、普通异常清除确认与故障ACK。
- 10 kHz PWM输送控制，低/中/高档占空比分别为65%/80%/100%。
- NG状态蜂鸣提示，菜单参数配置，完整输出帧率FPS和识别批次耗时DET显示。

显示增强独立于识别输入。FPS不是HDMI刷新率，DET不是摄像头到屏幕的端到端延迟。照片或单次显示值不能作为长期准确率统计。

## 开发环境与入口

- 工程文件：td_project/camera_to_dsi_display.al
- 工具记录：Anlogic TD 6.2.168116
- 器件：PH1P35MDG324，速度等级-3
- 摄像头：SC500CS
- 电机驱动：L298N

保持td_project与user_source同级。工程文件保留原始内容，Project Path仍记录开发电脑的路径；换机时应在TD中确认解压目录并另存工程。部分工具脚本使用本机安装路径，运行前按实际环境调整。

logo_idx.hex、logo_pal.hex、industrial_font16.hex是必要ROM资产。手动建立综合/实现Run时须将其复制至相应运行目录；tools/build_ae_once.ps1保留原资源复制逻辑。
