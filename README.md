# PH1P35 零件视觉识别

基于安路 PH1P35 与 SC500CS 的实时视觉工程，支持多目标零件形状/颜色识别、图像处理预览及曝光/增益控制。

当前正在修正摄像头偏绿：已撤除固定 1 倍补偿，改为自动从可用的中性场景像素估计白平衡，样本不足时保持最近有效补偿。无需白纸或 SW4 锁定。具体行为、诊断状态及验证边界见 [自动白平衡修正](docs/AUTO_WB_20261019.md)。现场偏绿和颜色准确率仍待上板核验。
